## Summary

Datasette Apps 0.4a0 has been released as sandboxed HTML and JavaScript applications inside Datasette that can run SQL queries. Version 0.4a0 adds support for linking via URL fragments, and supported URL schemes are reported back to Datasette Agent to assist in writing interconnected apps.
