## Summary

The author released a complete rewrite of Datasette Lite using service workers to run the Datasette Python application directly in the browser via WebAssembly and Pyodide. The update enables loading arbitrary SQLite databases, plugins, and specific SQLite versions for debugging and demos. The underlying architecture was developed out of an AI research spike generated using Claude Opus 4.8.
