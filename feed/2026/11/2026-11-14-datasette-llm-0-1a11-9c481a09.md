## Summary

datasette-llm version 0.1a11 has been released as an intermediate plugin for Datasette to support configuring LLMs for use with other plugins. This release adds support for OpenAI-compatible endpoints, allowing users to configure Datasette to use local models hosted with tools like LM Studio, Ollama, or llama.cpp.

## Why It Matters

It enables users to run a local server powered by a Datasette Agent instance running on their own local models via OpenAI-compatible endpoints.
